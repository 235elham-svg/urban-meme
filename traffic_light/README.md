# إشارة مرور ذكية - ESP32

## القطع
- ESP32
- حساس ألتراسونك HC-SR04
- 3 لدات (أحمر، أصفر، أخضر) + 3 مقاومات 220Ω
- زر ضغاط (Push Button)
- مقاومتين لمقسم الجهد: 1kΩ و 2kΩ
- بريدبورد وأسلاك

## التوصيل

| القطعة | الطرف | ESP32 |
|---|---|---|
| HC-SR04 | VCC | VIN (5V) |
| HC-SR04 | GND | GND |
| HC-SR04 | TRIG | GPIO 5 |
| HC-SR04 | ECHO | GPIO 18 **عبر مقسم جهد** |
| لد أحمر | الرجل الطويلة (+) عبر 220Ω | GPIO 25 |
| لد أصفر | الرجل الطويلة (+) عبر 220Ω | GPIO 26 |
| لد أخضر | الرجل الطويلة (+) عبر 220Ω | GPIO 27 |
| اللدات | الرجل القصيرة (-) | GND |
| الزر | طرف | GPIO 4 |
| الزر | الطرف الثاني | GND |

### مقسم الجهد للـ ECHO (مهم)
الحساس يطلع 5V والـ ESP32 يتحمل 3.3V بس:

```
ECHO ──[1kΩ]──┬── GPIO 18
              │
            [2kΩ]
              │
             GND
```

الزر ما يحتاج مقاومة لأن الكود يستخدم `INPUT_PULLUP`.

## طريقة العمل
1. الإشارة حمراء.
2. تقرب السيارة (أقل من 30 سم) وتضغط الزر ← أصفر ثانيتين ← أخضر.
3. لما تبتعد السيارة 3 ثواني (أو بعد 15 ثانية كحد أقصى) ← أصفر ← أحمر.
4. الضغط بدون سيارة قريبة ما يسوي شي.

تقدر تعدل المسافة والأوقات من قسم "الإعدادات" أعلى الكود.

## الرفع
- Arduino IDE ← Board: **ESP32 Dev Module**
- Serial Monitor على **115200** تشوف المسافة وتغير الحالة.

### لو قطعتك ESP8266 (NodeMCU)
غيّر الأطراف إلى:
```cpp
const int TRIG_PIN   = D1;
const int ECHO_PIN   = D2;   // عبر مقسم الجهد
const int RED_PIN    = D5;
const int YELLOW_PIN = D6;
const int GREEN_PIN  = D7;
const int BUTTON_PIN = D3;
```
